# TV-Brands-Market-Analysis-EDA
📊 TV Brands Market Analysis | Exploratory Data Analysis (EDA)  This project focuses on a comprehensive exploratory data analysis (EDA) of the TV brands market, aiming to uncover patterns, trends, and insights from consumer preferences, pricing strategies, and brand performance. The analysis helps understand how various TV brands compete 
The dataset used in this analysis includes multiple attributes such as brand name, screen size, resolution type, price, ratings, smart features, and customer feedback. Using Python libraries like Pandas, NumPy, Matplotlib, Seaborn, and Plotly, the data was cleaned, visualized, and analyzed to identify correlations and trends across brands and product categories.

The data cleaning stage involved handling missing values, removing duplicates, and standardizing categorical variables for consistent analysis. Following this, univariate and bivariate analyses were conducted to explore how pricing and features differ across brands. For instance, visualizations showed that premium brands tend to offer larger screen sizes and higher resolutions, while budget-friendly brands capture a significant share in the mid-price segment with smart TV features.

Key insights revealed that:

Customer ratings are strongly influenced by brand reputation and value-for-money perception.

Screen size and resolution significantly impact pricing, with Ultra HD models commanding higher prices.

Smart TV features have become a standard expectation, even among mid-range brands.

Brand loyalty plays a crucial role in influencing repeat purchases and customer satisfaction.

Through this EDA, the project provides a data-driven perspective on how consumers evaluate TV brands and what factors shape purchasing decisions. The findings can help marketers, product designers, and analysts understand competitive dynamics and identify opportunities for differentiation.

Overall, this analysis demonstrates how EDA techniques can transform raw data into actionable insights, guiding better decision-making in the consumer electronics market.
